# MeetBetter Demo Video Script

This guide will help you create a compelling 2-3 minute demo video showcasing MeetBetter's key features.

## Recording Setup

### Tools (Choose one)
- **macOS Built-in:** QuickTime Player (File → New Screen Recording)
- **Professional:** OBS Studio (free, more control)
- **Quick & Easy:** Loom (free, auto-uploads)

### Settings
- **Resolution:** 1920x1080 (1080p)
- **Frame Rate:** 30fps
- **Audio:** Enable microphone for voiceover
- **Window Size:** Make MeetBetter window large and centered

## Pre-Recording Checklist

- [ ] Close unnecessary apps and notifications (Do Not Disturb mode)
- [ ] Clean desktop background
- [ ] Have API keys ready in Settings
- [ ] Test audio levels
- [ ] Prepare a YouTube video for dual audio demo
- [ ] Have a script/bullet points ready

## Demo Script (2-3 minutes)

### Scene 1: Introduction (10 seconds)
**Visual:** MeetBetter app launched, home screen
**Voiceover:**
> "MeetBetter is a real-time meeting transcription app built with Tauri, Rust, and React. Let me show you its key features."

---

### Scene 2: Basic Transcription (30 seconds)
**Actions:**
1. Click "Start Live Transcription"
2. Speak clearly: "This is a demo of MeetBetter's real-time transcription. Notice how fast the text appears with just 1-2 seconds of latency."
3. Click "Stop Transcription"

**Voiceover (while speaking into mic):**
> "First, the real-time transcription. Watch how quickly it captures my speech with sub-2-second latency powered by Deepgram."

---

### Scene 3: AI Summary (20 seconds)
**Actions:**
1. Click "Generate" button
2. Wait for AI summary to appear
3. Show the structured summary with key points and action items

**Voiceover:**
> "After stopping, I can generate an AI-powered summary with key points, action items, and decisions using Groq."

---

### Scene 4: Dual Audio Capture - THE KILLER FEATURE (45 seconds)
**Actions:**
1. Click "Clear All"
2. Show Settings briefly (mention BlackHole setup)
3. Click "Start Live Transcription"
4. Play a YouTube video (e.g., news clip or interview)
5. While video plays, also speak into microphone
6. Show transcript with "Participant:" and "You:" labels clearly visible

**Voiceover:**
> "Here's the game-changer: dual audio capture. I've set up BlackHole virtual audio device to separate system audio from my microphone."
>
> [Play video]
>
> "Watch this - the YouTube video appears as 'Participant' while my voice shows as 'You'. This solves the 'who said what' problem in virtual meetings."
>
> [Speak into mic while video plays]

---

### Scene 5: Save & Manage Meetings (20 seconds)
**Actions:**
1. Stop transcription
2. Click "Save Meeting"
3. Enter title: "Product Demo Meeting"
4. Show Past Meetings list
5. Click on saved meeting to view it

**Voiceover:**
> "I can save meetings with custom titles and easily access them later from the Past Meetings section."

---

### Scene 6: Calendar Auto-Start (Optional - 15 seconds)
**Actions:**
1. Click Settings
2. Show Calendar Integration section
3. Show "Auto-start on meeting time" toggle
4. Show upcoming meetings list

**Voiceover:**
> "MeetBetter can auto-start transcription when your calendar meetings begin, with support for Zoom, Teams, Google Meet, and more."

---

### Scene 7: Closing (10 seconds)
**Visual:** Show GitHub page or final app view
**Voiceover:**
> "MeetBetter is open source and ready to test. Check out the GitHub repo for installation instructions and testing guide."

**Text Overlay:**
- GitHub: github.com/venkateswarisudalai/MeetBetter
- Download: [releases link]

## Pro Tips

### Recording Quality
- **Speak clearly** and at a moderate pace
- **Pause briefly** between sections for easier editing
- **Show, don't tell** - let the UI speak for itself when possible
- **Keep cursor movements smooth** - no erratic clicking

### Editing Tips
- Remove long pauses or mistakes
- Speed up AI generation waits (2x speed)
- Add subtle background music (copyright-free)
- Add text overlays for key features
- Include captions for accessibility

### Free Music Sources
- YouTube Audio Library
- Bensound.com
- Incompetech.com

### Video Editing Tools (Free)
- **macOS:** iMovie (built-in)
- **Cross-platform:** DaVinci Resolve, Kdenlive
- **Online:** Clipchamp, Canva

## Example Voiceover Script (Full)

```
[INTRO - 10s]
"MeetBetter is a real-time meeting transcription app built with Tauri 2.0, Rust, and React.
Let me show you what makes it special."

with automatic detection for Zoom, Teams, Google Meet, Webex, and Slack."

[CLOSING - 10s]
"MeetBetter is open source and ready to test. Visit the GitHub repo for installation
instructions and a 5-minute quick start guide. Thanks for watching!"
```
