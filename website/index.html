One-Command Install

Open Terminal and paste:

curl -fsSL https://vantage-meeting-app.netlify.app/install.sh | bash

Or Manual Install

  1. Download the DMG above and open it
  2. Drag to Applications — Drag Vantage.app into your /Applications folder
  3. First launch — Right-click the app → "Open" (this bypasses Gatekeeper once)
  4. Grant permissions — Allow Microphone and Screen Recording when prompted

Setup API Keys (Free)

  1. Deepgram — Sign up at deepgram.com (free $200 credit)
  2. Groq — Sign up at console.groq.com (free tier)
  3. Paste both keys into Vantage Settings

Note: Since this is an open-source app without Apple Developer signing, macOS may show a security warning on first launch. Right-click → "Open" to proceed safely. We're working on getting proper Apple notarization.
